# examples

Sequencias completas de comandos para casos recorrentes. Cada arquivo pode ser
executado direto com `@`, depois de carregar a estrutura e o pacote:

    load sistema.pdb
    run /caminho/pymol-molviz/molviz.pml
    @/caminho/pymol-molviz/examples/figura_membrana.pml

Ou lido como referencia e copiado comando a comando.
