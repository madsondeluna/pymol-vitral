# examples

Sequências completas de comandos para casos recorrentes. Cada arquivo pode ser
executado direto com `@`, depois de carregar a estrutura e o pacote:

    load sistema.pdb
    run /caminho/pymol-vitral/vitral.pml
    @/caminho/pymol-vitral/examples/figura_membrana.pml

Ou lido como referência e copiado comando a comando.
